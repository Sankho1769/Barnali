# Accessibility checklist
- [ ] Verify text/background contrast for all color pairings using WCAG contrast tooling.
- [ ] Use `#007780` for small text links rather than `#00AEBB`.
- [ ] Do not rely on color alone for warnings, errors, verification status, or vote state.
- [ ] Ensure keyboard-visible focus styles on interactive elements.
- [ ] Ensure icon-only controls have accessible names.
- [ ] Give meaningful illustrations concise alt text; mark decorative imagery with empty alt text.
- [ ] Check reflow at 320 CSS px and at 200% zoom.
- [ ] Test keyboard navigation and screen-reader labels in real components.
- [ ] Respect reduced-motion preferences for animations.
