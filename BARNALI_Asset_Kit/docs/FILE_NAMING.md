# File naming convention

Use lowercase kebab-case and descriptive names:
- `barnali-logo-horizontal.svg`
- `avatar-placeholder.svg`
- `needs-verification.svg`
- `room-card-empty-state.svg`

Rules:
1. Include the brand name for brand-level assets.
2. Describe the purpose, not the software used to create it.
3. Use SVG for scalable logos and UI icons.
4. Use `.webp` or `.avif` for optimized photographic content; PNG only where transparency/raster support is required.
5. Avoid generic names such as `final2.svg`, `new-logo.svg`, or `asset1.png`.
