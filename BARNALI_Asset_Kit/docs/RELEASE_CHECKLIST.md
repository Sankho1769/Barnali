# Asset release checklist
- [ ] Confirm approved logo lockup and tagline.
- [ ] Verify all SVG files render in target browsers.
- [ ] Export required PNG/ICO/app icons at official target sizes.
- [ ] Validate color contrast and focus visibility.
- [ ] Test header, feed, room, profile, message and settings layouts at mobile/tablet/desktop breakpoints.
- [ ] Optimize all photographic assets as WebP/AVIF.
- [ ] Verify filenames, alt text, license/ownership and attribution records.
- [ ] Remove unused files and confirm no secrets/user data are included.
- [ ] Run frontend lint, typecheck and build in the actual application repository.
