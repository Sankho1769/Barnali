Contains account registration, server session endpoints, principal loading/current identity, password change/recovery, HMAC rate limiting, and isolated owner bootstrap. Authentication-sensitive reads/writes use fixed database routines in the proposed V3 migration; ordinary member/admin queries remain direct JDBC behind RLS. The bootstrap runner uses the dedicated execute-only provisioner settings and two one-time routines. V3 is not applied and live PostgreSQL authentication tests remain pending. MFA/email verification are not implemented.
