# BARNALI asset catalog

## Brand
- `brand/logos/barnali-logo-horizontal.svg`: horizontal logo for headers.
- `brand/logos/barnali-logo-stacked.svg`: centered logo with tagline.
- `brand/logos/barnali-wordmark.svg`: wordmark-only usage.
- `brand/logos/barnali-mark.svg`: square mark on ivory, app/avatar use.
- `brand/logos/barnali-mark-transparent.svg`: transparent-background mark.
- `brand/logos/barnali-mark-dark.svg`: mark on forest-green square.
- `brand/logos/barnali-logo-dark-background.svg`: light wordmark for dark surfaces.
- `brand/logos/favicon.svg`: favicon source.
- `brand/social/barnali-social-card.svg`: social share card.

## UI
- `ui/icons/*.svg`: individual line icons, 24×24 viewBox.
- `ui/avatars/avatar-placeholder.svg`: default avatar.
- `ui/badges/*.svg`: reusable badge visuals.
- `ui/illustrations/empty-discussions.svg`: empty feed state.
- `ui/illustrations/verification-notice.svg`: verification information state.

## Design system
- `design-system/tokens/barnali.tokens.json`: canonical tokens.
- `design-system/themes/light.css`: light theme.
- `design-system/themes/dark.css`: dark theme.
- `design-system/barnali.css`: base style helpers.

## Screens
- `screens/responsive-dashboard-preview.html`: responsive dashboard concept.
- Additional feature screen folders are reserved for screen-by-screen implementation assets; the HTML preview is illustrative, not a full app.
